# Motion Graphics 2D

Use hierarchy, grids, negative space, readable type, color, and motivated motion to make graphic sequences legible. Select shapes, paths, mattes, and transitions to fit the message and timing. For camera-led or volumetric work, use the 3D or cinematography companion skill.
